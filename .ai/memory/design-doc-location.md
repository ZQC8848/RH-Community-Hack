The design doc for the core gameplay (Ring-Sphere beat targets, levels generated by
recording a real person's VR controller trajectory instead of hand-authored charts) is
at [`Docs/Idea - VR Rhythm Game Interaction Paradigm.md`](../../Docs/Idea%20-%20VR%20Rhythm%20Game%20Interaction%20Paradigm.md)
in this repo. Status as of 2026-08-20: concept stage — open questions include
the beat-detection algorithm, ring lead-time calibration across BPMs, hit-tolerance
tuning, and multi-sphere/two-hand beats.

**Why it matters:** this is the spec the interaction system (see
[../decisions/modular-portable-interaction.md](../decisions/modular-portable-interaction.md))
is being built against.

**How to apply:** the source of truth is the author's Obsidian vault
(`D:\ObsidianVault\Ideas\`); the copy in this repo may be stale if the Obsidian version
was edited afterward — check dates before treating the repo copy as current.
